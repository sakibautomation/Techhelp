Before cleaning ink: read the ET-2800 nozzle-check pattern

If you own an Epson EcoTank ET-2800 or ET-2803, the official control-panel guide gives a concrete way to distinguish a printer-side ink problem from a document that prints blank. This is not a procedure for every Epson or other-brand printer.

  1. Check for an error on the printer display, extend the output tray, and load a few sheets of plain paper.
  2. On this model family, press Home if needed, choose Maintenance, then Nozzle Check, and press the printer's Start button to print the diagnostic pattern. Follow the exact on-screen prompts for your device.
  3. Compare the printed pattern with the examples in the official manual before deciding whether any maintenance action is appropriate.

1. Print a built-in test page

Use the printer's display or control buttons to find a Printer Status Report, Print Quality Report, Nozzle Check, or similar test. Check your official printer manual for the exact location.

  • Built-in page is blank: concentrate on ink or toner, printheads, cartridge installation, or a hardware fault.
  • Built-in page looks normal: investigate the document, print settings, computer driver, or app.

Start with a controlled test page.

Use print preview and a simple document to distinguish software layout from the printer's own print mechanism.

2. Check ink or toner status without assuming the estimate is exact

Look at the printer's supplies screen or its official companion app. A low-ink warning can explain faint or blank output, but estimated ink levels are not always precise. If you recently installed a cartridge, verify it is compatible with the exact model and properly seated. Follow the manufacturer's instructions for removing protective tape or seals; do not touch electrical contacts or nozzles unnecessarily.

3. Run a nozzle check before a cleaning cycle (inkjet printers)

For an Epson ET-2800 or ET-2803, use the model-specific pattern and cleaning limits above.

Inkjet printers can develop blocked nozzles, especially after long periods without use. Print the manufacturer-provided nozzle check pattern. Missing lines or colors suggest a print-quality problem. If the pattern is incomplete, use the printer's recommended cleaning procedure, then retest.

Avoid repeated back-to-back cleaning cycles. They can consume substantial ink. Follow the manufacturer's limits and waiting periods. If the printer uses a replaceable printhead, check the manual before attempting removal or cleaning.

4. Check toner installation and imaging components (laser printers)

For a laser printer, verify that the toner cartridge is correctly installed and that any shipping seal was removed according to the official setup instructions. Some printers have separate drum or imaging units. Do not open sealed toner cartridges, touch hot internal parts, or attempt to repair the fuser. If the printer's own status page is blank after correct installation, use the manufacturer's troubleshooting guide.

5. Try printing a simple text document

Open a new document, type a short sentence in black, and print a single page. If this works while a particular PDF or webpage prints blank, the issue is likely tied to that file or application rather than the printer's ink supply.

6. Check print preview, page range and color settings

  1. Open Print Preview and confirm that text or images appear.
  2. Check the selected printer and the page range; avoid an empty selection or unintended blank page.
  3. Make sure text isn't white on a white background.
  4. For color documents, try a black-and-white test if your printer supports it. A missing color can affect the output differently across printer models.

7. If only PDFs print blank, isolate the PDF app

Try another known-good PDF. If only one file fails, reopen or re-download it from a trusted source. Check whether its print preview displays content. In Adobe Acrobat Reader, the Print as Image option under advanced print settings can sometimes help with rendering problems, but may print more slowly. Use this only for files you trust.

8. Check the printer driver and queue on Windows 11

Go to Settings → Bluetooth & devices → Printers & scanners, select the correct printer, and inspect the queue. If jobs are stuck, see our Windows 11 print queue guide. If the printer's built-in page works but all Windows jobs are blank, confirm the exact model and install the appropriate driver from the official manufacturer website. Avoid third-party driver download sites.

When the page is faint or streaked

If part of the printer’s own pattern appears, compare the missing lines or colours with the example in your model’s manual. Use the faded and streaked pages guide for inkjet, laser and scanner-specific checks.

When to stop troubleshooting

If the printer reports a hardware error, leaks ink or toner, smells hot, or makes unusual mechanical noises, stop printing and follow the manufacturer's safety instructions. Repeated cleaning or replacing supplies without a clear diagnosis can be costly. Keep a note of your printer model, test-page result and any error code before contacting support.

Frequently asked questions

Why does my printer print blank pages even with new ink?

A new cartridge may still have protective tape, may not be seated properly, or may be incompatible. Inkjet nozzles can also be blocked. First check the printer's built-in test page and the official setup instructions.

Can a bad driver cause blank pages?

Yes. If the printer prints its own status page correctly but documents from one computer come out blank, driver or app settings are worth checking.

Should I clean the printhead manually?

Not unless the manufacturer's manual explicitly recommends it for your model. Incorrect cleaning can damage components; use the built-in nozzle check and approved cleaning process first.

If content is visible but cut off along the edges, see our printer printing cut-off pages guide for paper size, scaling and margins.
