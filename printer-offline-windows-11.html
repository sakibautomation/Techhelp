How to Fix Printer Offline in Windows 11: 9 Checks

Publisher: Printer Resolve · Preparation: AI-assisted drafting; references identified in the article · Method and corrections

No physical device test or independent technician certification is claimed unless explicitly documented.

Jump to: Troubleshooting steps · Frequently asked questions

If Windows 11 says your printer is Offline, the computer may not be able to communicate with it. This can happen even when the printer is switched on. Use the comparison below to choose your first check. After each change, try the same one-page document on the affected PC.

Original decision analysis · Network / Windows / printer

A more precise way to diagnose “Offline”

Before reinstalling a driver, use two independent observations: can the printer create its own status page? and can another already-authorized device print to it? A printer-generated page checks the printing mechanism without asking Windows to send a job. A second device provides a comparison of the connection and selected print path. Neither test alone proves the final cause.

Windows port check: use the printer's current address, not an old label

If the printer is on Wi-Fi or Ethernet, check the current address displayed by its own network report. On the affected Windows PC, an authorized user can inspect configured ports with the documented PowerShell command Get-PrinterPort. A manually configured printer entry that still points to an address used before a router replacement is a specific clue worth checking. Not every printer uses a simple TCP/IP port: WSD and other discovery methods have different behaviors.

Some network printers use RAW TCP port 9100. Only when the exact model's documentation confirms that protocol, a non-destructive check such as Test-NetConnection -ComputerName 192.168.1.50 -Port 9100 can test whether that endpoint accepts a TCP connection. Replace the illustrative address with the verified device address; do not run it against a random network address. A failed connection on an unsupported port does not establish a broken printer, and success does not establish that a print job will finish.

Similarly, a failed ping may reflect filtered ICMP rather than a disconnected printer. A calculated common subnet is useful but does not prove that router isolation or local security rules permit printing. Do not expose printing ports on the public internet to solve a local printing problem.

Illustrative comparison: a network printer reports 192.168.1.88, but a saved manual Windows port points to 192.168.1.40. This mismatch warrants checking the correct Windows device entry before replacing toner or reinstalling a driver. These addresses are examples, not evidence from a physical printer we tested.

Sources: Microsoft's Windows printer troubleshooting guidance, Get-PrinterPort documentation, and Test-NetConnection reference.

Before you start: Make sure the printer has paper, no obvious error message, and is powered on. If you are using a shared office printer, check with your IT administrator before changing network or driver settings.

1. Choose the next check from the printer’s results

  • Another device prints to this printer over the same connection. Leave the printer running. Go straight to the queue on the affected PC.
  • The printer’s own status page works, but several devices cannot print. Check the shared connection. Ask the owner before restarting shared equipment.
  • The printer has an error or cannot print its own page. Record the message and follow the exact model’s instructions for that error.

If you have no second device, use the printer’s own status page if available, then inspect the queue on your PC. Leave any untested result open.

A Wi-Fi signal is only one clue.

Printer status, a valid network address and the Windows queue each provide a different piece of evidence.

2. Check the printer connection

For Ethernet, check the cable and the address on the printer’s current network report. For USB printers, reseat the cable at both ends and try a different USB port. For Wi-Fi printers, check the printer's network display or settings page to confirm it is connected to the correct network. Your computer and printer generally need to be on networks that can communicate with each other. Guest Wi-Fi networks may isolate devices.

3. Open the queue on the affected Windows 11 PC

  1. Open Settings → Bluetooth & devices → Printers & scanners. Select the physical printer you intend to use and choose Open print queue.
  2. Print a one-line document to that same printer. Watch for that job in the queue. If it appears in another queue, correct the selection in the app and try again.
  3. If your job stays there, note its status. Cancel only your own test job if needed. Follow the stuck queue guide if a job will not clear.
If you already see the classic Printer menu

Microsoft lists Pause Printing and Use Printer Offline under Windows 10. In a classic queue that offers these controls, clear a checked option only on a queue you manage. On current Windows 11, continue with Get Help below.

4. Run Get Help on the affected PC

Open Get Help from Start and search for printer troubleshooter. Follow the prompts for the intended printer and retry your one-page document. See Microsoft’s offline printer instructions.

5. Set a default only if Windows keeps choosing the wrong printer

If selecting the printer manually works, open Printers & scanners, turn off Let Windows manage my default printer if needed, and choose Set as default on the working entry.

6. Restart the affected PC if its queue still shows Offline

Save your work, restart that PC, reopen the same document and select the same printer. If it prints, stop here.

7. Restart the Print Spooler service

  1. Press Windows + R, type services.msc, and press Enter.
  2. Find Print Spooler.
  3. Right-click it and choose Restart. You may need administrator permission.

This restarts the service responsible for managing print jobs. Active queued jobs may be interrupted, so avoid this step while someone else is printing to a shared device.

8. Check for a driver or Windows update

Open Settings → Windows Update and install relevant updates. For printer-specific drivers, use the printer manufacturer's official support website. Avoid third-party “driver updater” tools and unsolicited download links.

9. Remove and re-add the printer as a last resort

If nothing else works, open Settings → Bluetooth & devices → Printers & scanners, select the printer and choose Remove. Then use Add device to set it up again. Before removing it, make sure you know how it connects and have access to any required setup information.

When the checks do not restore printing

Print a network configuration page using the printer's own controls, if available. If the printer cannot connect to Wi-Fi or shows a hardware error even without the PC, consult the manufacturer's support documentation. If only one computer is affected, focus on its printer configuration, driver, or network access.

Record the unresolved result

Note the printer brand and exact model, whether it connects by USB or Wi-Fi, the Windows status message, and whether another device can print. This helps distinguish a printer fault from a computer or network problem without sharing passwords.

Frequently asked questions

How do I get my printer back online?

Reconnect the printer to your Wi-Fi or USB connection, select the correct printer in Windows, check the queue and test printing. If Windows still reports offline, follow the numbered troubleshooting steps above.

Why does my printer say offline when it is turned on?

Powering on does not guarantee a working connection. Wi-Fi changes, USB problems, an incorrect printer selection, a stuck queue, or outdated drivers can all make Windows report the printer as offline.

Will restarting the Print Spooler delete my documents?

Restarting the service can interrupt active print jobs. Check your queue afterward and resend a document if it did not print.

Does this guide apply to HP, Canon, Epson, and Brother printers?

Most Windows-side checks apply across brands, but wireless menus and driver installation steps differ by model. Consult the manufacturer's official instructions for device-specific steps.
